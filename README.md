# Osama Shawki – Portfolio

Static site: `index.html`, `style.css`, `script.js`, `assets/`.

## Run locally
Open `index.html` in a browser, or run `python -m http.server 8000` and visit http://localhost:8000.

## Before publishing
- Put your CV at `assets/Osama-Shawki-CV.pdf`.
- Replace `YOUR-USERNAME` (GitHub), `YOUR-PROFILE` (Facebook/Instagram) and `20XXXXXXXXXX` (WhatsApp number, country code first) in `index.html`.
- Add certificate images to `assets/certificates/` and replace the dashed `.cert` boxes with `<img>` tags.
- Fill in each project's "My contribution", dates, and GitHub/live links.
- Edit text in `index.html`; the Arabic version of any element is its `data-ar` attribute.
- Colors and fonts are the variables at the top of `style.css`.

## Publish on GitHub Pages
1. Create a repository named `YOUR-USERNAME.github.io` (or any name).
2. Upload all files, keeping the folder structure.
3. Settings → Pages → Source: "Deploy from a branch" → `main` / `(root)` → Save.
4. Your site goes live at `https://YOUR-USERNAME.github.io/` within a few minutes.
